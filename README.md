# TN Marginal Workers Assessment

## 📌 Project Overview
The **TN Marginal Workers Assessment** project focuses on analyzing the employment and socio-economic conditions of marginal workers in Tamil Nadu. Marginal workers are individuals employed for only a part of the year due to seasonal or irregular job opportunities.

This project aims to identify employment patterns, demographic details, income conditions, and welfare accessibility of marginal workers using data analysis, preprocessing, visualization, and predictive insights.

---

## 🎯 Objectives
- Analyze the demographic characteristics of marginal workers in Tamil Nadu.
- Study employment patterns and socio-economic conditions.
- Identify income levels and access to social welfare schemes.
- Perform data preprocessing and exploratory data analysis (EDA).
- Create visual dashboards for better understanding and decision-making.
- Generate meaningful insights for improving worker welfare.
